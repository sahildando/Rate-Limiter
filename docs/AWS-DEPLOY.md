# AWS Deployment — API Monitoring Platform

Dev-sized infrastructure generated by the **AWS Deployments** plugin (`/deploy`).

## Architecture

| Component | AWS service | Notes |
|-----------|-------------|-------|
| API | ECS Fargate + ALB | FastAPI via existing `backend/Dockerfile` |
| Worker | ECS Fargate | Celery check execution |
| Scheduler | ECS Fargate | Due-monitor polling |
| PostgreSQL | Aurora Serverless v2 | 0.5–1 ACU, encrypted |
| Redis | ElastiCache Serverless | Rate limits, locks, Celery queue |
| Secrets | Secrets Manager | JWT + Aurora credentials |
| Frontend | Amplify Hosting (manual) | Next.js — set `NEXT_PUBLIC_API_URL` to ALB URL |

Infrastructure code: [`infra/`](../infra/)

## Estimated monthly cost (dev)

| Service | Assumption | Est. cost |
|---------|------------|-----------|
| NAT Gateway | 1 gateway, light traffic | ~$32 |
| Aurora Serverless v2 | 0.5 ACU average | ~$45 |
| ElastiCache Serverless | Light dev traffic | ~$5–15 |
| ECS Fargate | 3 tasks × 0.25 vCPU / 512 MB | ~$25 |
| ALB | 1 load balancer | ~$18 |
| CloudWatch Logs | 7-day retention | ~$2–5 |
| **Total** | | **~$125–140 / month** |

> NAT + Aurora dominate dev cost. For a cheaper dev loop, keep using Render + Neon + Upstash ([DEPLOYMENT.md](../DEPLOYMENT.md)) until you need full AWS isolation.

## Prerequisites

```bash

# Node.js 20+ (for CDK)
node --version
```

## Deploy

```bash
chmod +x scripts/deploy-aws.sh

# First deploy (uses localhost CORS placeholder — update after frontend is live)
./scripts/deploy-aws.sh

# After Amplify frontend is deployed
CORS_ORIGINS=https://main.d1234.amplifyapp.com ./scripts/deploy-aws.sh
```

The script will:

1. `cdk deploy` the stack (VPC, Aurora, Redis, ECR, ECS services)
2. Build and push the backend Docker image to ECR
3. Roll ECS services to the new image
4. Run `alembic upgrade head` as a one-off Fargate task

## Frontend on Amplify

1. Connect your GitHub repo in [Amplify Console](https://console.aws.amazon.com/amplify/)
2. Set app root to `frontend`
3. Build settings (Next.js SSR):

```yaml
version: 1
frontend:
  phases:
    preBuild:
      commands:
        - npm ci
    build:
      commands:
        - npm run build
  artifacts:
    baseDirectory: .next
    files:
      - '**/*'
  cache:
    paths:
      - node_modules/**/*
```

4. Environment variable: `NEXT_PUBLIC_API_URL=https://<alb-dns-name>` (from stack output `ApiUrl`)

## Security defaults applied

- Aurora and ElastiCache in private subnets
- ECS tasks in private subnets (outbound via NAT)
- Encryption at rest on Aurora
- JWT secret generated in Secrets Manager
- Security groups: ALB → API only; API/worker → DB/Redis only
- ECR image scanning on push

## Troubleshooting

| Issue | Fix |
|-------|-----|
| `aws: command not found` | Install [AWS CLI v2](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) |
| ECS tasks fail health check | Check CloudWatch logs in `/aws/ecs/RateLimiterDev` |
| `CORS_ORIGINS must not point to localhost` | Re-deploy with production frontend URL in `CORS_ORIGINS` |
| Migration task fails | Verify Aurora security group allows ECS task SG on port 5432 |
